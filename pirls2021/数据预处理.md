### 数据预处理模块

数据预处理模块包含以下两个主要部分：

#### 1. 数据填补

数据填补部分提供了以下方法：

- **compute_missing()**
  - **功能**：计算每列缺失值的百分比或数量。
  - **参数**：
    - `df` : `pandas.DataFrame`，包含数据的DataFrame。
    - `normalize` : `boolean`，默认为`True`，表示是否计算百分比。
  - **返回值**：
    - `missing_df` : `pandas.DataFrame`，包含每列缺失值的百分比或数量的DataFrame。

- **missing_values_heatmap()**
  - **功能**：绘制热图以可视化缺失值（浅色表示缺失）。
  - **参数**：
    - `df` : `pandas.DataFrame`，包含数据的DataFrame。
    - `output_path` : `str`，默认为`None`，保存图像的路径。
    - `savefig_kws` : `dict`，默认为`None`，保存图像的选项。

- **impute_missing_values()**
  - **功能**：按照以下步骤填补缺失值：
    1. 基于强相关变量的一对一模型填补。
    2. 基于变量间互信息图的连通分量进行热甲板填补。
    3. 丢弃缺失值比例超过预定义阈值的记录。
    4. 对剩余缺失值进行整体热甲板填补。
  - **参数**：
    - `df` : `pandas.DataFrame`，包含潜在缺失值的数据框。
    - `num_vars` : 数值变量名。
    - `cat_vars` : 分类变量名。
    - `{num,mixed,cat}_pair_kws` : 默认为`None`，用于传递一对一模型填补的附加关键字参数。
    - `graph_thres` : 默认为0.05，基于互信息得分确定变量是否相似的阈值。
    - `k` : 默认为8，热甲板填补中考虑的邻居数。
    - `max_missing_thres` : 默认为0.33，单个观测值允许的最大缺失值比例。
  - **返回值**：
    - `final_pairs` : `pandas.DataFrame`，包含高度相关的变量对及其缺失值比例的DataFrame。

- **plot_imputation_distribution_assessment()**
  - **功能**：绘制每个变量在填补前后的分布比较图。
  - **参数**：
    - `df_prior` : `pandas.DataFrame`，填补前的DataFrame。
    - `df_posterior` : `pandas.DataFrame`，填补后的DataFrame。
    - `imputed_vars` : `list`，包含填补变量的列表。
    - `sample_frac` : 默认为1.0，如果小于1，则对每对变量进行随机抽样。
    - `{prior,posterior}_kws` : 默认为`None`，传递给`kdeplot`的附加关键字参数。
    - `output_path` : `str`，默认为`None`，保存图像的路径。
    - `savefig_kws` : `dict`，默认为`None`，保存图像的选项。

#### 2. 异常值处理

异常值处理部分提供了以下方法：

- **remove_outliers()**
  - **功能**：使用孤立森林算法（Isolation Forest）去除异常值。
  - **参数**：
    - `df` : `pandas.DataFrame`，包含数据的DataFrame。
    - `variables` : `list`，包含可能存在异常值的变量。
    - `iforest_kws` : 默认为`None`，孤立森林算法的超参数。
  - **返回值**：
    - `df_inliers` : `pandas.DataFrame`，包含非异常值的DataFrame。
    - `df_outliers` : `pandas.DataFrame`，包含异常值的DataFrame。

以上是 `clust-learn` 包中数据预处理模块的主要内容，涵盖了数据填补和异常值处理两个方面，提供了多种方法和参数设置，以满足不同的数据分析需求。
