# PIRLS Student Reading Literacy Analysis

基于 PIRLS 2021 数据的学生阅读素养分析项目。项目围绕学生阅读态度、阅读目的与阅读素养之间的关系，提供从国际数据库整理、缺失值处理和变量筛选，到潜在剖面分析、多层模型分析及可视化展示的一套研究材料与代码。

> English repository name: `pirls-student-reading-literacy-analysis`

## 项目目标

- 整理 PIRLS 2021 学生、学校及国家/地区层面的数据与代码本。
- 分析阅读兴趣、阅读信心和阅读目的等因素与阅读素养的关系。
- 使用潜在剖面分析（LPA）识别不同阅读特征的学生群体。
- 使用多层线性模型（HLM）考察学生、学校和国家/地区层面的差异。
- 通过交互式图表呈现教育数据分析结果。

## 研究流程

1. 导入 PIRLS 2021 数据并统一国家/地区及变量命名。
2. 识别特殊缺失值，对连续变量和分类变量分别进行处理。
3. 合并学生、学校及相关问卷数据，构建分析数据集。
4. 按阅读目的和阅读态度变量开展描述性统计与潜在剖面分析。
5. 建立学生、学校、国家/地区多层模型并检验交互效应。
6. 输出统计结果、诊断图及交互式可视化页面。

## 环境要求

数据处理与展示代码主要使用 Python 和 R。

- Python 3.9 或更高版本
- R 3.6 或更高版本
- Python Web 端依赖见 `2026031510-源码/requirements.txt`
- R 分析依赖见 `国际中文/analysis_code/requirements.txt`

## 快速开始

### 启动 Web 服务

```powershell
cd 2026031510-源码
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:BIGMODEL_API_KEY = "your-api-key"
python app.py
```

服务启动后，根据终端提示在浏览器中打开本地地址。未配置 `BIGMODEL_API_KEY` 时，依赖大模型接口的功能不可用。

### 运行 R 分析

```r
setwd("国际中文/analysis_code")
source("00_init_environment.R")
source("quick_start.R")
```

正式分析前，请先核对代码中的数据路径、变量名、抽样权重和缺失值编码是否与所使用的 PIRLS 数据版本一致。

## 数据说明

`01_数据文件/` 与 `02_参考资料/` 已随仓库公开，用于说明项目的数据结构与研究依据。其余 PIRLS 原始数据库、派生数据集、虚拟环境、缓存及密钥通过 `.gitignore` 排除，不进入 Git 历史。复现完整研究时，请从 IEA/PIRLS 官方渠道获取获准使用的数据，并按照本地目录结构放置。
